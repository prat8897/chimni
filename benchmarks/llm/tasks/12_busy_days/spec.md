# Busy days

Find the days that had more than `k` events.

**Inputs**
- `events`: a list of records, each with `day` (text such as `"mon"`) and `kind` (text).
- `k`: an integer.

**Output**
- A list of texts: each `day` that has strictly more than `k` events. Groups appear in the order their key first appears in the input.
