# Cheapest product

Find the name of the cheapest product.

**Inputs**
- `products`: a list of records, each with `name` (text) and `price` (integer).

**Output**
- The `name` of the product with the lowest `price`, or none (null) if there are no products.

**Edge cases**
- If several products share the lowest price, return the one that comes first in the list.
