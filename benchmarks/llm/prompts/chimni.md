## How solutions are run

Write a complete Chimni program: the signature line, then the rows. Put it in a ```chimni block. The program is run
with the task's inputs, by name; declare them in the signature in the order given with the task. Output slots
declared as `(a,b)` produce lists of pairs; a slot that may have no answer must be declared with `|none`.

The full language reference and a tutorial follow. If a task cannot be expressed in Chimni, reply with the word
CANNOT_EXPRESS and a one-sentence reason, and no code block.
